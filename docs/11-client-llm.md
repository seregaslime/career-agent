# Интервью с моделью пользователя

/chat — вход обязателен. История хранится в PostgreSQL отдельно для каждого пользователя. Модель вызывается браузером, а не сервером Render. Локальные модели не становятся доступны другим пользователям сайта.

## Ollama

1. Запустить Docker Ollama с опубликованным только на loopback портом, например 127.0.0.1:11434:11434. Сохранить том моделей.
2. Указать OLLAMA_ORIGINS=https://career-agent-9pq.pages.dev (для разработки добавить конкретный localhost origin). OLLAMA_HOST внутри Docker — 0.0.0.0:11434. Не публиковать модель в интернет.
3. Открыть /chat, проверить подключение, выбрать модель из /api/tags. Разрешить браузеру доступ к локальному ПО, если он запросит.
4. Подтвердить передачу контекста выбранной модели, отправить сообщение.

Подключение к произвольным LAN-адресам в этой версии не поддерживается, только localhost/127.0.0.1/[::1]. Вне Docker настройки OLLAMA_HOST могут отличаться.

## Внешний API

Режим совместимого API поддерживает /models и /chat/completions, адрес включает /v1. Допускается HTTPS либо loopback HTTP. Провайдер должен поддерживать CORS для нашего сайта: серверный прокси в этой версии отсутствует. Если /models не поддерживается, модель можно вписать вручную. Совместимость с конкретным платным провайдером не подтверждена без его ключа.

API-ключ хранится только в памяти компонента до ухода со страницы. Он отправляется исключительно выбранному API в Authorization, не передаётся backend Career Agent, не сохраняется в БД/localStorage. Cookies не передаются модели; перенаправления запрещены. При смене адреса требуется повторное согласие на передачу интервью.

## Сохранение и ограничения

Сначала сохраняется вопрос пользователя, затем вызывается модель; сбой не теряет сохранённый текст. Неполученный ответ можно запросить повторно, в том числе после перезагрузки. Если ответ получен, а сохранение не удалось, до закрытия страницы он остаётся в памяти и можно повторить только сохранение. У каждого сообщения клиентский UUID для безопасного повтора записи. Сохранённые ответы не перезаписываются.

Контекст модели — последние 20 пар вопрос/ответ (до 40 сообщений) и инструкция, вся история хранится отдельно. Ограничения: 200 пользовательских сообщений интервью, 4000 символов вопрос, 16000 символов ответа, ожидание модели до 3 минут. Лимит 200 сообщений пока без архивации/нового интервью. Ответы выводятся как текст, без исполнения HTML, команд или инструментов. Они не меняют профиль автоматически.

Это первая часть этапа 3: чат, сохранение и подключение модели. Извлечение структурированных фактов, их отдельное подтверждение и перенос в профиль остаются следующей частью этапа. Для сохранённых ответов нельзя доказать, что они созданы конкретной моделью: клиентские данные считаются недоверенными.

## Проверки

Тесты используют детерминированные ответы вместо реальных LLM. Проверяются владельцы сообщений, повтор записи, незавершённый ответ, изоляция аккаунтов, отсутствие изменений профиля, адаптеры Ollama/API, CORS/HTTP ошибки, отсутствие cookies и запрет redirect. Отдельная ручная проверка локальной Ollama не заменяет CI.
