## Уточнение связей старой диаграммы

Экспорт — самостоятельное действие после создания резюме. Импорт необязательно является расширением интервью: его можно запускать из профиля. Обновление рынка происходит фоново, поэтому каждый запрос подбора не обязан включать загрузку рынка. Дайджест и получение уведомления — две стороны одной доставки, а не обязательная include-связь. Таблица задаёт актуальную модель; PNG сохраняются как первоначальный концепт.
