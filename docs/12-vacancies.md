# Каталог вакансий — независимый этап

Работает отдельно от интервью, подтверждения фактов и профиля. Таблицы и миграции не добавлены: сейчас это получение по запросу и воспроизводимый демокаталог. Внешние результаты не сохраняются постоянно. Персональный рейтинг, извлечение требований LLM и план обучения в этот этап не входят.

## Готовый сценарий

Открыть /vacancies, выбрать источник, ввести текст и фильтры опыта/формата, нажать «Найти вакансии». Открыть карточку и вернуться к списку: фильтры и страница сохраняются в URL. Каталог доступен без регистрации; профиль и история диалога при поиске не читаются и не передаются источнику.

По умолчанию — шесть полностью вымышленных вакансий с явными отметками «Демо». Компании, зарплаты и условия не являются реальными предложениями, отклик и внешние ссылки отсутствуют. Поиск демоданных учитывает название, компанию, город и навыки. Фильтры опыта и формата применяются вместе с поиском.

## Контракт API

- GET /api/vacancies?source=demo&q=Python&experience=noExperience&work_format=REMOTE&page=0
- GET /api/vacancies/demo/1
- Для подготовленного адаптера: source=hh и GET /api/vacancies/hh/{числовой_id}.

Страница начинается с 0; размер — 20, предельная глубина — 100 страниц. Опыт: noExperience, between1And3, between3And6, moreThan6; пустое значение — любой. Формат: REMOTE, HYBRID, ON_SITE; пустое значение — любой. Поиск ограничен 120 символами.

Ответ списка: source, items, found, page, pages, fetched_at (UTC), hh_available. Нормализованная вакансия: id в пространстве источника, source, title, company, city, experience и experience_label, work_formats, salary, skills, description, published_at, source_url.

Зарплата сохраняет границы, валюту, gross и период выплат. Неизвестные условия не считаются подходящими и не додумываются. Формат занятости и количество часов пока не нормализованы и не фильтруются; уточнение этих условий — следующий шаг.

## Подключение hh.ru

Адаптер подготовлен по [официальной спецификации](https://api.hh.ru/openapi/redoc). [Условия API](https://dev.hh.ru/admin/developer_agreement) требуют регистрации приложения и выполнения требований к сервисам для поиска работы, включая информирование пользователей о соглашении hh.ru. Это ещё не настроено. Не включать источник до выполнения этих условий.

На 20 ноября 2026 контрольный запрос без настроенного доступа получил HTTP 403. У проекта пока нет зарегистрированного приложения и подтверждённого рабочего токена. Поэтому реальная интеграция не считается проверенной и source=hh без конфигурации возвращает 503 с понятным сообщением. Интерфейс предлагает явно перейти в демокаталог; скрытой подмены реальных данных синтетическими нет.

После оформления доступа и выполнения требований источника задать только в backend окружении:

- HH_ACCESS_TOKEN — действующий токен доступа зарегистрированного приложения.
- HH_USER_AGENT — идентификация зарегистрированного приложения и контакт по требованиям hh.ru.

Не сохранять токен в frontend, репозитории, чате или логах. Автоматическое получение/обновление OAuth-токена не реализовано; истечение доступа обрабатывается как недоступность источника. Подтверждение живого поиска и карточки с действующим доступом остаётся отдельной приёмкой.

Запросы разрешены только к фиксированному https://api.hh.ru/vacancies, редиректы запрещены, ID строго числовой. Сетевой тайм-аут — 8 секунд, ответ ограничен 2 МБ. Поиск использует text, experience, work_format, page, per_page. HTML в описаниях преобразуется в текст; неизвестные поля не исполняются. Ссылка на оригинал строится из числового ID. Дубли внутри полученной страницы объединяются по ID; постоянного импорта и межстраничного хранилища пока нет.

Для внешнего источника действует отдельный от входа лимит 10 запросов/мин на сетевого клиента одного процесса. За прокси несколько пользователей могут иметь общий адрес; перед расширением нагрузки нужно уточнить доверенную схему определения клиента. Кэширование и периодическое обновление пока отсутствуют; HH вызывается только по явному запросу пользователя.

## Координация с профилем

Новые файлы backend/app/vacancies.py, frontend/src/VacanciesPage.tsx и frontend/src/vacancies.css изолированы от работы над фактами. Общие файлы затронуты только для подключения маршрутов и backend-настроек. app/models.py, app/auth.py, app/chat.py, ProfilePage, ChatPage и Alembic не менялись.

Для следующего этапа согласовать со вторым разработчиком чтение подтверждённых навыков, направления, опыта и предпочтений. Текущий модуль не предполагает и не изменяет будущий формат фактов. Фильтрация каталога ещё не является персональным подбором.

## Проверки

Стандартные тесты используют синтетические данные и подменяют HH. Проверяются фильтры, пустые результаты, повторяемость, карточка, нормализация зарплаты/описания, дедупликация, неправильные параметры, безопасные ссылки, ошибки доступа/квоты и отсутствие утечки токена. Внешний HH не вызывается в CI.
