# Career Agent

Учебный командный проект: AI-помощник, который узнаёт опыт и интересы пользователя, помогает составить достоверное резюме, подбирает вакансии и предлагает план развития.

Статус: реализован каркас React/FastAPI/PostgreSQL, добавлены тесты и CI. Бизнес-функции и первый облачный выпуск в работе.

## Главный сценарий

Интервью → подтверждённый профиль → резюме → подходящие вакансии с объяснением → недостающие навыки → план обучения.

Не добавляйте в публичный репозиторий ключи API, персональные резюме и настоящие диалоги пользователей. Для примеров используйте синтетические данные.

## Каркас приложения

Быстрый запуск при работающем Docker:

```sh
cp .env.example .env
docker compose up --build
```

Интерфейс: http://localhost:8080. API: http://localhost:8000/docs.
`/api/health` проверяет процесс, `/api/ready` — доступность PostgreSQL и версию миграций.
Первая миграция создаёт только учёт версии схемы; пользовательские таблицы появятся вместе с авторизацией.

Для разработки без контейнеров:

```sh
uv sync --project backend --frozen
npm ci --prefix frontend
# PostgreSQL должен быть запущен; DATABASE_URL задаётся в окружении backend.
cd backend
uv run alembic upgrade head
uv run uvicorn app.main:app --reload
# В другом терминале из корня:
npm run dev --prefix frontend
```

Общие проверки: `python3 scripts/check.py`. Интеграционный тест миграций требует
`TEST_DATABASE_URL` отдельной временной PostgreSQL; без неё тест явно пропускается.
В CI тестовая PostgreSQL создаётся автоматически. Вход и редактирование профиля реализованы. Интервью, резюме и вакансии пока представлены страницами-заготовками.
